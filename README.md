# FTC Bot Builder

A web-based configuration tool for FTC robots.

## Features
- Configure motors, servos, sensors, odometry
- IMU and Limelight setup
- Blinkin LED patterns with FTC values
- AprilTag configuration
- Port conflict validation
- Save/Load configurations
- Export/Import JSON configs
- Print-friendly Driver Station setup guide

## Usage
Just open `index.html` in a browser, or visit the deployed URL.

## Deployment
This is deployed on Vercel/GitHub Pages.
